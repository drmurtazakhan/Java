The Menu Layout of Quadtree

There are five menu items: File, Compression Method, Input File, Options, and Help.

File menu

Users can choose "Exit" to end the application.

Input File menu

Users can input their own bitmap files. Only the bitmaps of size 8x8 or 16x16 are accepted by the application. Few demo files are included.

Options menu

Users can set the speed of the animation by moving the slider provided by the application.
