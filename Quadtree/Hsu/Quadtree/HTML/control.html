The Control Components of Quadtree

Control Components of the Layout

Trace

The Step button allows to trace through encoding of the bitmap file with the quadtree method.

Run

The Run button allows to start the encoding of the bitmap file with the quadtree method.

Stop

The Stop button allows to stop the simulation.

Reset

The Reset button allows to reset the screen. If user decides to change from Trace to Run, or vice versa, the Reset button must be pressed first.
